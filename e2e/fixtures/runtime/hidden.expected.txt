v-opacity visible opacity 0 counts as visible

h-contents-hidden hidden display contents without a visible child
v-contents-text visible display contents with a visible text child
h-cv-child hidden ancestor content-visibility hidden
v-cv-self visible content-visibility hidden on the element itself

v-summary visible

h-details-button hidden control in a closed details element
